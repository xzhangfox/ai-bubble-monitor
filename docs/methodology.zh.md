# 说明文档

数据从哪里来、指标是什么意思，以及模型如何验证。

## 先读懂这两件事

先做市场温度计，再检验温度计能不能预示下跌。

监测仪回答两个不同的问题：AI 相关市场现在有多过热？历史上的类似条件，是否预示过后续明显下跌？前者是透明的规则评分，后者是机器学习实验。

80 分表示这些指标相对于各自历史处于较高水平，不代表有 80% 的概率崩盘。模型预测的是明确定义的未来价格下跌事件，也没有直接给市场贴上“存在泡沫”的确定标签。

设计假设是：股价快速上涨、涨幅集中、资金更愿意冒险和企业激进投入，可能让市场更容易受到预期落空的冲击。这些是值得检验的线索，不是泡沫的证明，也不是下次下跌的因果解释。

## 数据来源与更新

使用每日市场行情，以及公司公开披露的财报。

| 来源 | 获取什么 | 用来做什么 |
| --- | --- | --- |
| Yahoo Finance | 通过 Chart 接口读取约十年的每日价格和成交量，参数为 range=10y、interval=1d。 | 计算 AI 股票组合、市场广度、波动率、债券风险偏好、利率和交易热度。 |
| SEC EDGAR · XBRL 财务数据 | 微软、Alphabet、亚马逊、Meta、Oracle 已披露的资本支出和营收。 | 计算五家公司合计的过去十二个月资本支出／营收；财报披露后才把相应数值计入历史。 |
| SEC EDGAR · 10-Q / 10-K 正文 | 季度和年度财报中关于采购、租赁等承诺的段落。 | 由 Gemini 提取有原文支持的金额和引文，单独展示承诺信息；这条文本提取流程本身不直接作为第八项评分输入。 |

AI 股票组合包含 NVDA、MSFT、GOOGL、AMZN、META、AVGO、ORCL。先把各股票价格归一到相同起点，再取平均，形成起始等权的组合。其他行情包括 ^VIX、^RUT、^TNX、HYG、IEF，并对齐到共同交易日。

GitHub Actions 在每周二至周六 UTC 11:15 定时运行，也可以手动触发。它在前一个美股交易时段结束后，并发拉取行情、计算指标、运行模型和大模型流程，再随网站发布 JSON/CSV 结果。这是按交易日更新的研究面板，不是逐笔推送行情。

Python 步骤可以分别失败，并保留各自上一次成功结果。因此行情、模型、财报和简报可能具有不同的截止日期；网站能打开不代表所有上游都更新成功。两次财报之间沿用上次已披露的资本支出数据；没有可用 SEC 序列时，评分使用七项市场指标。

## 八项指标与简单理解

从价格热度、风险偏好和企业投入几个角度观察市场。

| 指标 | 如何计算 | 简单理解 |
| --- | --- | --- |
| AI 股票上涨动量 | 组合过去 252 个交易日的涨幅。 | 大约一年里，AI 相关股票是不是已经涨了很多？ |
| 偏离长期趋势 | 组合价格／200 日均线 − 1。 | 价格是不是远远跑在自身近期趋势前面？它是价格代理指标，不是基于盈利的估值指标。 |
| 上涨是否集中 | 组合过去 126 个交易日涨幅，减去罗素 2000 同期涨幅。 | 是不是主要由 AI 龙头上涨，而较小的公司明显落后？ |
| 对波动过于放松 | VIX 取负值后，计算其历史百分位。 | 市场是不是认为短期不会有什么波动？低 VIX 也可能只是市场确实平静。 |
| 信用风险偏好 | HYG 过去 63 个交易日涨幅，减去 IEF 同期涨幅。 | 风险较高的公司债是否跑赢美国国债？它反映风险偏好，不直接测量投资者借了多少杠杆。 |
| 利率环境 | 十年期美国国债收益率取负值，再计算历史百分位。 | 较低的长期利率是否在支撑较高的资产价格？利率变化也有其他经济原因。 |
| 成交量放大 | 组合合计成交量的 20 日均值／252 日均值。 | 交易活动是不是变得特别活跃？仅凭成交量无法知道谁在买卖、为什么买卖。 |
| 资本支出强度 | 五家大厂合计的过去十二个月资本支出／合计营收。 | 企业相对于当前销售收入，是不是投入了越来越多的钱？这里是公司整体资本支出，不全是 AI 投资。 |

每个原始指标都转换为 0—100 的历史百分位，只使用截至当日已经出现的数据，包括当日。第 90 百分位表示读数高于约 90% 的历史比较值，不代表某事件有 90% 的概率发生。VIX 和十年期国债收益率取反，使较高的百分位统一对应假设中的较热环境。

综合分数是所使用指标的等权平均：有可用 SEC 序列时为八项，否则为七项。等权容易理解和检查，但不是训练得到的最优权重，也不自动代表有预测能力。

这些代理指标受到 Dalio、Shiller、Minsky 等公开泡沫框架的启发，不是复刻某个专有泡沫指数。价格和投入上涨，也可能来自真实盈利增长和有效投资。

## 模型与各自职责

对比简单模型和复杂模型，把文字生成与统计预测分开。

| 方法 | 输入 | 为什么使用 |
| --- | --- | --- |
| 综合评分校准 | 单个综合分数，通过逻辑回归映射成概率。 | 检验最简单的市场温度计，本身是否包含后续下跌的信息。 |
| 逻辑回归 · scikit-learn | 每项指标的历史百分位。 | 容易解释，可以查看各项指标如何改变估计；模型权重表达关联，不代表因果。 |
| 梯度提升树 · scikit-learn | 指标百分位，以及各指标大约一个月内的变化。 | 尝试发现非线性组合，例如多个警示信号同时升高。 |
| 小型 Transformer · PyTorch | 过去 60 个交易日的指标百分位序列。 | 检验信号逐步变化的过程，是否比单日读数提供更多信息；更复杂不保证更准确。 |

Gemini 负责另一类任务：从财报提取承诺信息，再根据已经准备好的事实撰写双语每日简报。默认使用 gemini-3-flash-preview，可以通过 GEMINI_MODEL 配置；它不直接生成核心统计模型的下跌概率。

提取的金额必须附带能在财报中逐字找到、且包含该金额的引文。简报中的数字会与输入事实核对，失败后只尝试修复一次，仍不通过就不发布。这些检查限制无依据输出，但不能保证时期、含义、完整性或翻译一定正确。

### 展开技术细节

多指标逻辑回归使用 C=0.5。HistGradientBoostingClassifier 使用最大深度 3、学习率 0.05、最多 200 次迭代、最小叶节点样本数 40，以及 L2 正则化 1.0。

Transformer 包含两层编码器，隐藏维度 32、四个注意力头、前馈维度 64、dropout 0.1。使用可学习位置参数、平均池化、二元交叉熵和 AdamW，最多训练 40 轮；数据足够时使用留有时间间隔的验证集进行早停。

首次训练至少使用 504 个可用交易日，此后训练集随时间逐步扩展。运行环境没有 PyTorch 时，会跳过 Transformer。

## 预测目标与验证方法

定义具体的未来价格事件，再在模型没训练过的后续时期检验。

主要目标是：未来 63 个交易日，大约三个月内，AI 组合是否曾有一天收盘价比今天低至少 10%？今天指数为 100，未来某天收盘达到 90 或以下就算发生。比较基准是今天的收盘价，不是未来某个高点，也不要求窗口结束当天仍下跌 10%。

按时间向前验证，每隔 63 个交易日重新训练。训练只使用未来结果窗口在测试期开始前已经结束的样本，并保留 63 个交易日的间隔。历史百分位只使用当时的过去数据，SEC 信息在披露后才计入，以减少未来信息泄漏。

同时固定报告两个其他目标：126 个交易日内下跌 15%，以及 252 个交易日内下跌 20%。这些目标一起展示，避免只挑表现最好的时间范围。

| 评价指标 | 简单理解 | 如何判断 |
| --- | --- | --- |
| 样本外 AUC | 模型能否把未来发生目标下跌的日子，排在没有发生的日子前面。 | 0.5 相当于随机排序，越高越好；AUC 高也不自动说明概率准确。 |
| Brier skill | 预测概率相对于简单历史频率基线，是否更加准确；每个测试阶段的基线由对应训练历史计算。 | 大于 0 表示优于基线，小于 0 表示更差；预测概率不代表事件保证发生。 |
| 95% 不确定性区间 | 把历史按约一个季度的连续区块重复抽样 1,000 次，观察表现估计的变化范围。 | 区间越宽，证据越不确定；区块抽样考虑部分时间相关性，但不会创造新的独立市场事件。 |

网站中的当前结果面板直接读取仪表盘使用的 model.json。结论沿用现有主模型标准：选中的模型必须 Brier skill 为正，且其 95% 区间下界也为正，才标记为优于基线。这是历史证据，不保证未来表现。

## 能说明什么，有什么局限

衡量市场是否异常，比预测它何时反转容易得多。

分数很高时，价格仍可能继续上涨。评分衡量的是假设中的过热特征；是否有助于预测定义好的下跌事件，需要由样本外验证回答。

当前组合把今天选定的主要 AI 相关公司应用到历史上，因此存在选样和幸存者方面的局限。公司整体资本支出、VIX、债券收益和成交量，也都不是 AI 投机程度的完美测量。

许多相邻交易日的标签来自同一轮下跌。几千条日线不代表几千次独立崩盘，因此回测另外报告分开的下跌事件数量。历史较短、事件较少，会限制结论可信度，复杂神经网络尤其如此。

金融关系会变化，数据源可能修订或失效，发布的结果也可能过时。当前回测属于研究结果，不能当作从未用于研究选择的最终独立实验；在同一段历史比较多种模型，也会引入模型选择的不确定性。

这个面板适合查看市场条件、比较解释和评估证据。目前没有建立可靠的泡沫破裂日期预测，也没有证明存在可盈利的交易策略。
